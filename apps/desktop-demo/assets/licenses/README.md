# Desktop demo asset notices

## Catamp Silverplay skin

The bundled `catamp-silverplay.wsz` is Cranamp's Catamp Silverplay, copied from
[`samoylenkodmitry/cranamp`](https://github.com/samoylenkodmitry/cranamp/tree/232dfe39588ccb2ec1e418458c7c11e5ceee3a4e/assets/skins)
at revision `232dfe39588ccb2ec1e418458c7c11e5ceee3a4e`. Cranamp distributes the
repository under Apache License 2.0; the full license is included here as
`catamp-APACHE-2.0.txt`.

## Clair de lune MIDI sequence

The bundled `music/clair-de-lune.mid` is Claude Debussy's "Clair de lune" from
the Suite bergamasque, sequenced by Bernd Krueger and published at
[piano-midi.de](http://www.piano-midi.de) (edition 2011-08-20, copyright 1998
by Bernd Krueger). The file is unchanged. Its author licenses it under
[CC BY-SA 3.0 DE](https://creativecommons.org/licenses/by-sa/3.0/de/deed.en):
copies and adaptations name Bernd Krueger and piano-midi.de and carry the same
license. The Music tab shows this credit beside the title of the piece. The
license covers this file and not the code of the demo.

## Remaining asset review

- `TwemojiMozilla.ttf` embeds emoji artwork. Mozilla's source project records
  Apache-2.0 for its code and CC BY 4.0 for the Twemoji artwork. No matching
  attribution or license notice was found beside Cranpose's bundled font.
- The bundled Noto Sans fonts appear to be under the SIL Open Font License;
  the repository includes OFL notices for optional language fonts but none
  beside the desktop demo's `NotoSansBold.ttf` and `NotoSansMerged.ttf` files.
- The XKCD tab retrieves and displays comics from xkcd.com. Randall Munroe's
  published license allows reuse noncommercially with attribution; it does
  not grant commercial reuse. Keep the tab out of commercial distributions or
  get permission and add the required attribution.
- `github-mark.svg` has an MIT notice in the source tree. Keep that notice with
  copies of the GitHub mark.

This inventory flags visible notice and distribution questions; it is not a
legal opinion. Review the font files' embedded metadata and upstream version
before preparing a commercial release.

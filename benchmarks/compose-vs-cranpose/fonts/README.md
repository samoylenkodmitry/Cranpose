# Roboto for the desktop apps

The Huawei Mate 20 X's own `/system/fonts/Roboto-Regular.ttf`,
`Roboto-Medium.ttf` and `Roboto-Bold.ttf` (Roboto 2.138, Copyright 2011
Google Inc., licensed under the Apache License, Version 2.0). Every desktop
app loads these files from `PERF_FONTS`, so all of them shape and measure
the faces the Android apps read from the phone.

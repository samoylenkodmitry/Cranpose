# The budgets of the steady-frame ledger, scripts/perf/steady_ledger.sh (#2247).
#
# One row a layout of the bench app in the desktop window, a frame of the 60
# frames counted after 60 warm-up frames: `malloc` calls (`calloc` and
# aligned allocations with them), `realloc` calls, blocks left live
# (allocations minus frees), the bytes that memcpy calls copy (`copied`) and
# the bytes that `realloc` calls keep (`realloc_bytes`), which a `realloc`
# copies when it moves the block. `wall-t20-start` is the still wall's start
# at tier 20 (composition, layout, scene and the first frame packet), the
# same values divided by the nodes that the applier holds after it, and its
# allocator calls a node by group (scripts/perf/steady_ledger_groups.txt).
# `dashboard` is the ESP32 dashboard of the framebuffer bench.
#
# One value a line: ROW METRIC BUDGET SPREAD. The budget is the highest value
# of three runs of one build (`steady_ledger.sh --repeats 3`), the spread the
# highest minus the lowest. A value fails when it passes its budget plus its
# spread; `copied` and `realloc_bytes` also get 2% of their budget, as
# inlining that an unrelated change shifts moves them. Lower a budget in the
# commit that earns the cut.
#

# The budgets of the steady-frame ledger, scripts/perf/steady_ledger.sh (#2247).
#
# One row a layout of the bench app in the desktop window, a frame of the 60
# frames counted after 60 warm-up frames: `malloc` calls (`calloc` and
# aligned allocations with them), `realloc` calls, blocks left live
# (allocations minus frees), the bytes that memcpy calls copy (`copied`) and
# the bytes that `realloc` calls keep (`realloc_bytes`), which a `realloc`
# copies when it moves the block. `wall-t20-start` is the still wall's start
# at tier 20 (composition, layout, scene and the first frame packet), the
# same values divided by the nodes that the applier holds after it, and its
# allocator calls a node by group (scripts/perf/steady_ledger_groups.txt).
# `dashboard` is the ESP32 dashboard of the framebuffer bench.
#
# One value a line: ROW METRIC BUDGET SPREAD. The budget is the highest value
# of three runs of one build (`steady_ledger.sh --repeats 3`), the spread the
# highest minus the lowest. A value fails when it passes its budget plus its
# spread; `copied` and `realloc_bytes` also get 2% of their budget, as
# inlining that an unrelated change shifts moves them. Lower a budget in the
# commit that earns the cut.
#
# Measured on samarch (x86-64 Linux, glibc 2.44, valgrind 3.25.1), main
# 2fc547b0d, three runs.
# The rows of wall-t20, patchwork-t17, gauntlet-t16, gauntlet-t12, feed,
# ticker, layers and dashboard come from one run at the head of #2406, the
# text cache that keeps returning texts, on main 268b97781; spreads as before.
# The malloc and realloc rows of patchwork-t17 come from six runs at the
# heads of #2430, one culled walk a frame, on main ffe937570: the highest of
# them; spreads as before. The copied rows of grid-layer and deep-layer and
# the realloc and realloc_bytes rows of layers, grid and grid-layer come from
# one run at each of its last two heads on main 5e4770c63, which gave equal
# values.
# The charts rows come from three runs of that row alone on main 0edf9547e
# with the layout added.
# The gauntlet-t16 realloc row comes from five runs (`--repeats 5`) at 53ebad4ad
# of #2403 on main 8341807fa.
# The patchwork-t17 realloc row comes from five runs of steady_frames on main
# 8341807fa (30.48 to 30.77, matching PR head 30.40 to 30.63). The dashboard
# malloc row covers main 8341807fa (27.67) and main b1134eb70 (27.62).
# The realloc and realloc_bytes rows of patchwork-t17, gauntlet-t16,
# gauntlet-t12 and feed come from the ledger A/B of the text layout's run
# room (#2512) on main 2bd350b35, one run; spreads as before.
# The copied rows of wall-t20-start, grid and deep come from the kept base
# runs of six mains, ab2504b04 to c7f25f08f, and the head of #2508, which read
# the same value each. The dashboard realloc row spans what runs of equal
# code read, 0.30 to 0.50 a frame (#2247), as the start's calls move.
# The ticker's copied spread holds both modes of the scene store's shape
# chunk compaction (`keep_live_runs`), whose copies differ by 2,920 B from
# run to run of one binary for a reason not yet known (#2247).

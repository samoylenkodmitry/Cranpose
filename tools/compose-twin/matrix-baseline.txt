# A clip or graphics layer followed by an offset. In Compose the layer wraps
# the offset's coordinator, so the offset moves the content inside the layer
# and the layer clips it (clipToBounds explicitly, alpha by compositing
# offscreen at the layer's bounds). Cranpose bakes a node's offsets into its
# position and bounds the layer at the node's rect, so the content moves
# with its clip and nothing is cut. Tracked in issue #902.
